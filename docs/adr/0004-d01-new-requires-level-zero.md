# 0004. D01: «Новая» — это ни разу не показана и уровень 0

## Контекст

Изначально предполагалось, что состояние «Новая» определяется только тем, что фраза ни разу не показывалась. При реализации ядра выяснилось: при такой привязке ручная смена состояния у ни разу не показанной фразы не меняла ни её вес, ни отображаемое состояние.

## Решение

Фраза считается новой, только если она ни разу не показывалась и её уровень равен 0. Ручной уровень выше нуля у ни разу не показанной фразы сразу задаёт её состояние и вес по уровню. Вес и состояние вычисляются одним правилом, состояние в базе не хранится.

## Почему

Рассмотрен вариант оставить правило «новая — только по числу показов». Отвергнут: ручная пометка «Знаю» у свежей фразы продолжала бы показывать её с максимальным весом, то есть ручная смена не меняла бы частоту показа. Вариант хранить состояние отдельным полем отвергнут: два источника правды расходились бы.

## Последствия

- Ручной уровень 0 у ни разу не показанной фразы неотличим от «Новая»: поставить «Не знаю» нельзя до первого показа, только после него (в таблице состояний уровни 0–1 — «Не знаю»).
- «Новая» по-прежнему получает наибольший вес, поэтому ручное снижение до 0 ничего не меняет, а повышение — меняет.
- Правило одно и для веса, и для состояния; статистика и библиотека обязаны брать его оттуда же, а не считать своё.
