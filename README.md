# Win Deutsch

## Что это

Небольшая программа для Windows 10/11 x64, которая живёт в трее и показывает немецкие
фразы «на периферии внимания», пока вы работаете. Два режима показа:

- **Виджет** — маленькое полупрозрачное окно поверх всех окон, фраза меняется по интервалу;
- **Карточка** — всплывает по интервалу, висит N секунд и исчезает, не забирая фокус.

Перевод показывается как выбрано: сразу, по клику, через N секунд или никогда. Часть показов
превращается в тест «Что это означает?» с четырьмя вариантами. Кнопки «Знаю / Не знаю / Позже»
и ответы в тестах меняют, как часто фраза попадается. С первого запуска есть базовый набор из
8 тем (Работа, Быт, Врач, Телефонные разговоры, Behörden, Small Talk, Путешествия, Частые
немецкие выражения), а рядом с программой лежат словари — 8 категорий, 30 тем, около 9 тысяч
слов и фраз (бизнес и предпринимательство, искусственный интеллект, трудоустройство,
домохозяйство, инженерные науки, медицина, деньги и налоги, образование), которые подключаются
сами при запуске. Свои темы и фразы — в окне «Библиотека». Программа молчит при полноэкранных
приложениях, в тихие часы и пока вас нет за компьютером. Работает без интернета, сетевых
обращений нет, всё хранится локально.

Стек: C# + WPF на .NET 8, SQLite. Подробности — в [docs/architecture.md](docs/architecture.md).

## Установка и запуск

1. Скачайте готовый архив `WinDeutsch-win-x64.zip` со страницы
   [Releases](https://github.com/viktorplus/win-deutsch/releases/latest) (или соберите сами
   командой `scripts\publish.ps1` — архив появится в `dist\`).
2. Распакуйте архив в любую папку, например `C:\Programs\WinDeutsch\`. Внутри —
   `WinDeutsch.exe` и папка `dictionaries\`; они должны лежать рядом. Устанавливать .NET не нужно
   (self-contained). Нужна Windows 10/11 x64.
3. Запустите `WinDeutsch.exe`. Программа не подписана, поэтому Windows может показать окно
   SmartScreen: «Подробнее» → «Выполнить в любом случае».
4. При первом запуске создаётся папка данных, база с базовым набором, подключаются все словари
   из `dictionaries\`, и в трее появляется уведомление «Win Deutsch работает — значок в трее».
   Какие темы показывать, выбирается галочками в «Библиотеке».

Повторный запуск exe не создаёт второй экземпляр — он открывает «Библиотеку» первого.
Закрытие окон библиотеки и настроек программу не завершает; выход — только «Выход» в меню трея.
Автозапуск включается галочкой «Запускать с Windows» (настройки или меню трея; по умолчанию выкл.).

## Словари

Папка `dictionaries\` рядом с `WinDeutsch.exe`: подпапка — категория, файл `.tsv` — тема
(`dictionaries\Медицина\Тело и симптомы.tsv` → тема «Тело и симптомы» в категории «Медицина»).
Формат файла — как у импорта (см. ниже): `немецкий<TAB>русский`, строки с `#` — заголовки разделов.

- **Подключение.** При каждом запуске программа подключает словари, которые ещё не подключала:
  создаёт тему в категории и добавляет фразы. Подключённые файлы запоминаются в `settings.json`
  (`importedDictionaries`), поэтому повторно они не добавляются.
- **Свой словарь.** Положите `.tsv` в `dictionaries\<Категория>\` и перезапустите программу
  (выход через меню трея) — он подключится сам.
- **Вернуть удалённое.** «Библиотека» → «Словари…»: отметьте темы — добавятся только недостающие
  фразы, прогресс по остальным сохраняется.
- **Удалить категорию.** Выберите категорию в дереве «Библиотеки» → «Удалить категорию»: удаляются
  все её темы, фразы и история показов (после подтверждения). Удалённый словарь при следующем
  запуске не возвращается. Отдельную тему удаляет «Удалить тему».

## Данные и резервные копии

Папка данных: `%LOCALAPPDATA%\WinDeutsch\` (можно переопределить переменной окружения
`WINDEUTSCH_DATA_DIR`).

| Файл | Что внутри |
|---|---|
| `data.db` | SQLite: темы, фразы, уровни знания, история показов |
| `settings.json` | настройки; неизвестные ключи при сохранении не теряются |
| `log.txt` | необработанные исключения и ошибки |
| `backups\` | автокопии `auto-before-restore-<время>.zip`, создаются перед восстановлением |

Побитые файлы не роняют программу: `settings.json` переименовывается в
`settings.json.broken-<время>`, `data.db` — в `data.db.broken-<время>`, после чего создаются
новые (база — с базовым набором), а в трее показывается уведомление.

**Как сделать копию.** Настройки → вкладка «Данные» → «Создать резервную копию» — получится zip
с `data.db` и `settings.json` в выбранной папке. «Восстановить из копии» (после подтверждения)
сначала сохраняет текущее состояние в `backups\`. Вручную: закройте программу («Выход» в трее)
и скопируйте папку `%LOCALAPPDATA%\WinDeutsch\`.

## Горячие клавиши

Глобальные, включаются и выключаются в настройках (по умолчанию включены). Если сочетание уже
занято другой программой, в настройках оно помечается «занято», остальные работают.

| Сочетание | Действие |
|---|---|
| Ctrl+Alt+→ | следующая фраза |
| Ctrl+Alt+← | предыдущая фраза |
| Ctrl+Alt+Пробел | показать перевод |
| Ctrl+Alt+P | пауза / продолжить (пауза «пока не сниму») |
| Ctrl+Alt+H | скрыть / показать виджет |

## Формат импорта

Импорт — «Библиотека» → «Импорт»: из файла `.txt/.csv/.tsv` или вставкой текста. Одна строка —
одна фраза:

```
немецкий<разделитель>русский[<разделитель>тема]
```

- Разделитель определяется по строке: табуляция, затем `;`, затем ` — ` или ` - `.
- Третья колонка (необязательная) — тема: фраза попадёт в тему с этим именем, тема создаётся при
  необходимости. Без третьей колонки — в тему, выбранную в диалоге.
- Строки, начинающиеся с `#`, и пустые строки пропускаются (комментарии).
- Кодировка: UTF-8 (с BOM и без) или Windows-1251 — определяется автоматически.
- Строка без разделителя принимается как фраза без перевода; ошибка — только пустой немецкий текст.
- Дубликаты (тот же немецкий текст без учёта регистра и пробелов в той же теме) пропускаются.
  Перед импортом диалог показывает, сколько строк будет добавлено, сколько дубликатов и
  ошибочные строки с номерами.

Пример:

```
# Работа
Ich habe einen Termin um drei.	У меня встреча в три часа.	Работа
Können Sie das bitte wiederholen?; Не могли бы вы повторить?; Телефонные разговоры
Keine Ahnung - Понятия не имею
Guten Morgen — Доброе утро
```

Экспорт (в `.tsv`: немецкий, русский, тема) использует тот же формат, поэтому повторный импорт
экспорта дубликатов не создаёт.

## Сборка и тесты

Нужен .NET 8 SDK (`winget install Microsoft.DotNet.SDK.8`).

```
dotnet build WinDeutsch.sln -warnaserror
dotnet test WinDeutsch.sln
scripts\publish.ps1
```

`scripts\publish.ps1` выполняет `dotnet publish src/WinDeutsch.App -c Release -r win-x64
--self-contained -p:PublishSingleFile=true -o dist`, кладёт `WinDeutsch.exe` и `dictionaries\`
в `dist\` и упаковывает их в `dist\WinDeutsch-win-x64.zip` (папка в `.gitignore`). Запуск из исходников: `dotnet run --project src/WinDeutsch.App`.
Для проверок задавайте `WINDEUTSCH_DATA_DIR` во временную папку, чтобы не трогать свои данные.

Тесты покрывают только `WinDeutsch.Core` (xunit, без UI); приложение WPF проверяется запуском.

## Ресурсы (измерено)

Замер опубликованного `dist\WinDeutsch.exe` на Windows 11 x64: запуск с `WINDEUTSCH_DATA_DIR`
во временной папке, интервал по умолчанию (1 мин), режим «Виджет», 25 с ожидания
(замер 2026-10-06).

| Показатель | Значение |
|---|---|
| Размер exe | 164 160 457 байт (156,6 МБ) |
| **Приватный рабочий набор** (счётчик `Process\Working Set - Private`) через 25 с | **45,9 МБ** |
| Полный рабочий набор (`WorkingSet64`) через 25 с | 135,0 МБ |
| Приватная память (`PrivateMemorySize64`, выделенная, не только резидентная) | 67,3 МБ |
| Процессорное время за 25 с (включая запуск) | 1,61 с |
| Созданные файлы (прежний замер, 30 с) | `data.db` (92 КБ), `settings.json` (1 КБ) |

Метрика для ориентира «памяти — до 100 МБ» — **приватный рабочий
набор**: его Диспетчер задач показывает по умолчанию в колонке «Память». Он равен 45,9 МБ и в
ориентир укладывается. Полный рабочий набор (135 МБ) — отдельный показатель: в основном это
общие отображённые страницы single-file бандла и рантайма .NET/WPF, которые разделяются с
системой и в приватную память процесса не входят; по нему ориентир не оценивается. Процессорное
время включает старт (распаковка single-file, JIT); показатель в простое после старта нужно
проверить вручную в Диспетчере задач. ReadyToRun/trimming не включались.

## Что проверить вручную

Тесты проверяют ядро; окна и системное поведение — только руками. Чек-лист (используйте `WINDEUTSCH_DATA_DIR` во временной папке):

- [ ] Первый запуск: 8 тем, не менее 400 фраз, режим «Виджет» в правом нижнем углу, одно
  уведомление в трее.
- [ ] Виджет перетаскивается за любое место, позиция сохраняется после перезапуска.
- [ ] Размер виджета меняется за угол и числами в настройках, сохраняется; «Закрепить
  позицию» отключает перетаскивание и изменение размера.
- [ ] Кнопки управления появляются при наведении, без наведения виден только текст;
  «всегда видны» работает.
- [ ] Кнопки ◀ ▶ 👁 ✓ ✗ ⏰ ✕; «◀» неактивна на первой фразе.
- [ ] Меню ⏸ (15 мин / 1 час / до завтра / пока не сниму): виджет пишет «Пауза до …» и показывает
  одну кнопку ▶.
- [ ] Меню ⋯: «Исключить из обучения», «Повторить чаще», «Открыть в библиотеке».
- [ ] Значок в трее: левый клик, меню; на паузе значок серый.
- [ ] Уведомление в трее при первом запуске и при повреждённых `settings.json`/`data.db`.
- [ ] Режим «Карточка»: всплывает на мониторе с курсором в выбранном углу, не забирает фокус,
  не появляется на панели задач, пока курсор над ней — не исчезает, закрывается сама.
- [ ] Тест «Что это означает?»: подсветка верного/неверного, ссылка «Не знаю», при 100 % каждый показ
  — тест; ответ меняет состояние.
- [ ] Перевод в режимах «сразу», «по клику», «через N секунд», «никогда» — отдельно для виджета и
  карточки.
- [ ] Полноэкранное приложение (игра/видео/презентация): виджет прячется, карточки не появляются;
  после выхода всё возвращается.
- [ ] Тихие часы, в том числе переход через полночь: виджет скрыт, карточек нет.
- [ ] Блокировка экрана (Win+L) и простой ≥ 5 мин: фразы не меняются; после возвращения
  отсчёт заново.
- [ ] Диалог «Создать резервную копию» создаёт zip с `data.db` и `settings.json`; «Восстановить
  из копии» просит подтверждение, кладёт автокопию в `backups\`, данные видны сразу.
- [ ] Диалог импорта: предпросмотр (добавится / дубликаты / ошибки с номерами), UTF-8 и Windows-1251,
  комментарии `#`.
- [ ] Диалог экспорта в `.tsv` и повторный импорт без дубликатов.
- [ ] Горячие клавиши Ctrl+Alt+→/←/Пробел/P/H работают; занятое другой программой сочетание
  помечено «занято» в настройках.
- [ ] Прокрутка списка из 10 000 фраз в библиотеке без задержек; поиск и фильтры.
- [ ] Вкладки «Статистика» и «История»; групповые действия.
- [ ] «Запускать с Windows»: запись в автозагрузке появляется и исчезает.
- [ ] Отключение монитора: окно не теряется.
- [ ] Повторный запуск exe открывает библиотеку первого экземпляра, процесс один.
- [ ] Настройки: закрыл — открыл, значения те же; неверное значение подсвечивается и не
  сохраняется.
- [ ] Память и CPU в простое — Диспетчер задач; ориентир ≤ 100 МБ, фактический замер см. выше.
